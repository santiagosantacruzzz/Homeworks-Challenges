# Gestor de Contactos - Challenge 02

App en React que lista, agrega y elimina contactos, simulando una carga
inicial de datos.

## Cómo correr el proyecto

```bash
npm install
npm run dev
```

## Estructura

- `src/App.jsx` — componente principal y estado global
- `src/main.jsx` — punto de entrada de React
- `index.html` — HTML base
